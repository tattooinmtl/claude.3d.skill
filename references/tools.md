## meshy_text_to_3d

Generate an untextured 3D PREVIEW from a text prompt; texture it afterwards with meshy_text_to_3d_refine once the user approves. Typically 2–3 minutes.
Cost: 20 credits (meshy-7.1 / latest / meshy-6), 5 (meshy-6-lite, meshy-t2, meshy-t2.5); Ultra geometry +5.

PREFER THE IMAGE ROUTE: for higher quality and more control, generate a design image first (meshy_text_to_image), let the user approve it, then meshy_image_to_3d with input_task_id = the image task (textured in one task). Use direct text-to-3d for a quick draft or when the user explicitly asks for it.

Examples:
  - Low-poly: { prompt: "dragon", model_type: "smart-topology", ai_model: "meshy-t2", target_polycount: 4000 }
  - Max detail: { prompt: "ornate knight helmet", ai_model: "meshy-7.1", geometry_resolution: "4k" }
  - 3D print: { prompt: "cat", target_formats: ["obj"] }

**Parameters**

- `prompt` (required) - string: What to model (max 800 characters)
- `ai_model` (one of latest | meshy-7.1 | meshy-6 | meshy-6-lite | meshy-7 | meshy-t2 | meshy-t2.5) - string: 'latest' (default, = Meshy 7.1) or 'meshy-7.1' (best), 'meshy-6', 'meshy-6-lite' (fast, cheap, 2K textures only); 'meshy-7' is deprecated. With model_type smart-topology: 'meshy-t2' (the default there) or 'meshy-t2.5' (newest, sharper detail for game assets).
- `model_type` (one of standard | smart-topology | lowpoly) - string: standard (default); smart-topology (ai_model meshy-t2 or meshy-t2.5): a clean, part-separated, triangle-only mesh made directly at target_polycount, ignoring remesh/decimation; lowpoly is deprecated (billed like meshy-6, retires 2026-10-30).
- `geometry_resolution` (one of standard | 2k | 4k) - string: Ultra geometry pass: standard (default), 2k or 4k (finest); meshy-7.1/latest with model_type standard only, +5 credits.
- `ultra_mode` - boolean: Deprecated: use geometry_resolution '2k'.
- `topology` (one of quad | triangle) - string: quad or triangle (default).
- `target_polycount` - integer: Standard: remesh target 100–300,000, needs should_remesh true. Smart Topology: meshy-t2 100–15,000 (default 4,000), meshy-t2.5 100–30,000 (default 15,000).
- `decimation_mode` - integer: Adaptive decimation 1 (ultra) – 4 (low); overrides target_polycount.
- `symmetry_mode` (one of off | auto | on) - string: Deprecated: has no effect.
- `should_remesh` - boolean: Remesh to target_polycount / topology (default false).
- `pose_mode` (one of a-pose | t-pose) - string: 'a-pose' or 't-pose'; use 't-pose' when the model will be rigged or animated.
- `target_formats` - array: Formats to produce (default: all but 3mf; list '3mf' to get it). Fewer formats finish faster.
- `alpha_thumbnail` - boolean: Also return a transparent-background preview (alpha_thumbnail_url).
- `auto_size` - boolean: AI-estimate the real-world height and resize to it (default false).
- `origin_at` (one of bottom | center) - string: 'bottom' or 'center' (default bottom with auto_size).
- `response_format` (one of markdown | json, default "markdown") - string: markdown (default) or json

Returns a structured result (the server declares an output schema).

## meshy_get_task_status

Wait for a task to finish (wait=true, default) or check it once (wait=false). Reports the task's real task_type; pass it to the download and cancel tools.

wait=true polls at the API's suggested interval (else 5s→30s backoff) until SUCCEEDED / FAILED / CANCELED or timeout_seconds runs out; a failed status check (timeout, 429, 5xx) is retried at the next poll. Running out of time returns outcome "TIMEOUT": the task keeps running on Meshy — call again with the same task_id (Meshy advises allowing up to 60 minutes from creation).

**Parameters**

- `task_id` (required) - string: Task ID
- `task_type` (one of text-to-3d | image-to-3d | multi-image-to-3d | remesh | retexture | rigging | animation | text-to-image | image-to-image | convert | resize | uv-unwrap | multi-color-print | print-analyze | print-repair | print-split | text-to-motion | creative-lab-figure-prototype | creative-lab-figure-build | creative-lab-lamp-prototype | creative-lab-lamp-build | creative-lab-keychain-prototype | creative-lab-keychain-build | creative-lab-fridge-magnet-prototype | creative-lab-fridge-magnet-build | creative-lab-vinyl-figure-prototype | creative-lab-vinyl-figure-build | creative-lab-brick-figure-prototype | creative-lab-brick-figure-build | creative-lab-keycap-prototype | creative-lab-keycap-build | creative-lab-fidget-pixel-prototype | creative-lab-fidget-pixel-build | creative-lab-fidget-collapsible) - string: Optional: if omitted or wrong, the server finds the task and reports its real type.
- `wait` (default true) - boolean: true (default): poll until it finishes; false: return the current status.
- `timeout_seconds` (default 300) - integer: Max wait for this call when wait=true; the task keeps running after it.
- `response_format` (one of markdown | json, default "markdown") - string: markdown (default) or json

Returns a structured result (the server declares an output schema).

## meshy_list_tasks

List tasks of any status, newest first by default, merged across the types queried (one request per type). Default: text-to-3d, image-to-3d, multi-image-to-3d, text-to-image and image-to-image; pass task_type / task_types for printing, rigging, animation, motion, post-processing or Creative Lab tasks. status and phase filter the fetched tasks, so a page can be shorter than limit; continue with next_offset while has_more. Types whose request failed are listed in failed_types. For finished 3D models only, meshy_list_models is cheaper.

## meshy_cancel_task

Cancel a queued task, or delete a finished one. What happens depends on the task:

Creative Lab tasks (task_type "creative-lab-..."):
  - PENDING → canceled, credits refunded
  - IN_PROGRESS → canceled, credits NOT refunded
  - SUCCEEDED / FAILED / CANCELED → cannot be canceled or deleted, even with confirm_delete

Every other task:
  - PENDING → deleted, credits refunded
  - IN_PROGRESS → refused: the task keeps running and its credits are not refundable. Wait until it finishes
  - SUCCEEDED / FAILED / CANCELED → PERMANENTLY deleted with its files, no refund. Requires confirm_delete: true — ask the user first

Returns { success, task_id, task_type, previous_status, message }.

**Parameters**

- `task_id` (required) - string: Task ID
- `task_type` (one of text-to-3d | image-to-3d | multi-image-to-3d | remesh | retexture | rigging | animation | text-to-image | image-to-image | convert | resize | uv-unwrap | multi-color-print | print-analyze | print-repair | print-split | text-to-motion | creative-lab-figure-prototype | creative-lab-figure-build | creative-lab-lamp-prototype | creative-lab-lamp-build | creative-lab-keychain-prototype | creative-lab-keychain-build | creative-lab-fridge-magnet-prototype | creative-lab-fridge-magnet-build | creative-lab-vinyl-figure-prototype | creative-lab-vinyl-figure-build | creative-lab-brick-figure-prototype | creative-lab-brick-figure-build | creative-lab-keycap-prototype | creative-lab-keycap-build | creative-lab-fidget-pixel-prototype | creative-lab-fidget-pixel-build | creative-lab-fidget-collapsible) - string: Optional: if omitted or wrong, the server finds the task and reports its real type.
- `confirm_delete` - boolean: true to permanently delete a finished task, only after the user agreed.

## meshy_download_model

Save a finished task's output under meshy_output/ (project folders with history), or at save_to.

- 3D tasks: ONE model format — ask the user which first (GLB viewing, OBJ white-model printing, 3MF multicolor printing, FBX game engines, USDZ AR, BLEND Blender); never download all. A format exists only if it was generated: 3mf needs target_formats ["3mf"] at creation, meshy_convert or meshy_process_multicolor.
  - Creative Lab: omit format to save every part.
  - Images and text-to-motion clips save their own files and ignore format.
  - Rigging and animation tasks are not saved: they return their file URLs.
If a download fails, its URL is returned instead.

Example (print): { task_id: "abc-123", format: "obj", print_ready: true, print_height_mm: 100 }

**Parameters**

- `task_id` (required) - string: Task ID
- `task_type` (one of text-to-3d | image-to-3d | multi-image-to-3d | remesh | retexture | rigging | animation | text-to-image | image-to-image | convert | resize | uv-unwrap | multi-color-print | print-analyze | print-repair | print-split | text-to-motion | creative-lab-figure-prototype | creative-lab-figure-build | creative-lab-lamp-prototype | creative-lab-lamp-build | creative-lab-keychain-prototype | creative-lab-keychain-build | creative-lab-fridge-magnet-prototype | creative-lab-fridge-magnet-build | creative-lab-vinyl-figure-prototype | creative-lab-vinyl-figure-build | creative-lab-brick-figure-prototype | creative-lab-brick-figure-build | creative-lab-keycap-prototype | creative-lab-keycap-build | creative-lab-fidget-pixel-prototype | creative-lab-fidget-pixel-build | creative-lab-fidget-collapsible) - string: Optional: if omitted or wrong, the server finds the task and reports its real type.
- `format` (one of glb | fbx | usdz | stl | obj | blend | 3mf) - string: Model format (default glb; omit for every Creative Lab part).
- `include_textures` (default true) - boolean: Also save the texture maps
- `save_to` - string: Absolute file path to save to instead of meshy_output/{timestamp}_{prompt}_{id}/
- `parent_task_id` - string: Earlier task of the same chain (e.g. the preview of a refine); saves into its project folder.
- `print_ready` - boolean: OBJ only: rotate Y-up to Z-up, scale to print_height_mm, center, bottom at Z=0. Changes only the local file (free); meshy_resize (1 credit) rescales the model on Meshy.
- `print_height_mm` - number: Height in mm with print_ready (default 75; '15 cm' → 150).

## meshy_list_usage

List the team's finished API tasks with the credits each consumed, newest first. Free. Use it to break down spend per endpoint or API key. Only for API keys on a Studio or Enterprise team (others get 403).

Covers SUCCEEDED and FAILED tasks (FAILED ones are refunded, so they show 0); a task still running is not listed yet. Without start_time / end_time it covers the last 30 days.

Returns { records: [{ task_id, endpoint, status, created_at, finished_at, consumed_credits, api_key_name, api_key_suffix }], page_num, page_size, has_more }

Example (September image-to-3d spend): { start_time: "2026-09-01T00:00:00Z", end_time: "2026-10-01T00:00:00Z", endpoints: ["image-to-3d"], page_size: 100 }

**Parameters**

- `page_num` (default 1) - integer: Page number
- `page_size` (default 20) - integer: Records per page
- `sort_by` (one of -created_at | +created_at, default "-created_at") - string: '-created_at' newest first (default) or '+created_at'
- `start_time` - string: RFC 3339 start of the created_at window (default: 30 days before end_time; at most 1 year).
- `end_time` - string: RFC 3339 end of the window (default now).
- `endpoints` - array: Only these endpoints ('text-to-3d' covers preview and refine). Omit for all.
- `status` (one of SUCCEEDED | FAILED) - string: Only tasks with this final status. Omit for both.
- `response_format` (one of markdown | json, default "markdown") - string: markdown (default) or json
